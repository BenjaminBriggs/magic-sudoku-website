W-Wing

Two squares with the same two notes, linked through a row, column or house where one of those numbers has only two places; one of the squares must hold the other number, so any square that sees both can't.

Worked example

W-Wing in Action

How to spot it

  1. 1Look for two squares with the same two notes that don't see each other.
  2. 2Pick one of the two numbers. Find a row, column or house where it has only two places, one seeing each square.
  3. 3One of those places holds the number, so the square it sees can't: that square is the other number.
  4. 4Cross the other number off any square that sees both squares.

What it does

Crosses notes off, usually one or two.
