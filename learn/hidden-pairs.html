Hidden Pair

Two numbers that can only go in the same two squares of a row, column or house, so those squares can't be anything else.

01Worked Example 02Triples and Quads

Worked example

Hidden Pair in Action

How to spot it

  1. 1Pick a row, column or house, and for each number it still needs, find the squares it can go in.
  2. 2Look for two numbers that can only go in the same two squares.
  3. 3Those squares must hold those two numbers, so cross every other note off them.

What it does

Crosses notes off. What's left is a Naked Pair, which may cross off more.

Triples and Quads

Three numbers that can only go in the same three squares work the same way, and so do four in four. A number needn't be a note in every one of the squares, as long as it can't go anywhere else.
