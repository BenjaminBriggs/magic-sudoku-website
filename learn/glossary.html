Sudoku Glossary

Essential terms and definitions for understanding Sudoku solving techniques. Bookmark this page for quick reference while learning!

01Grid Structure 02Solving Methods 03Technique Categories Quick Reference
1

Grid Structure

House

One of the nine 3×3 boxes in the grid. Each house holds the numbers 1 to 9, each just once.

Also called: box, block, nonet

Line

A row or column, running the full width or height of the grid. Each holds the numbers 1 to 9, each just once.

Lines can be horizontal (rows) or vertical (columns)

Square

One of the 81 places for a number in the grid. Each square belongs to one row, one column and one house.

Also called: cell, position

2

Solving Methods

Notes

The small numbers you write in a square for the numbers that could still go there. As you rule numbers out, you cross their notes off, until one is left.

Also called: candidates, pencil marks

Ruling Out

A number is ruled out of a square when its row, column or house already has it. If eight numbers are ruled out, the ninth goes in the square.

How every number is found in the end

Crossing Off

Taking a note out of a square once a technique shows the number can't go there. Most techniques cross notes off rather than place a number.

Also called: elimination

Given

A number in the puzzle from the start. Some are given to start you off, and they can't be changed.

Also called: clue, starting number

3

Technique Categories

Singles

Techniques that place a number. The foundation of all Sudoku solving.

Naked Single
A square with only one number left that fits, because its row, column and house already use the other eight.
Hidden Single
A number with only one square left in a row, column or house, so it goes there, whatever else that square could hold.

Intersection

Locked Candidates: techniques that use the squares where a house and a row or column overlap to cross notes off.

Pointing
A number whose squares in one house all sit in one row or column, so it can't go anywhere else in that line.
Claiming
A number whose squares in a row or column all sit in one house, so it can't go anywhere else in that house.
Locked Candidates lesson

Sets

Techniques built on a few squares of a row, column or house and the numbers they share. Triples and quads work the same way as pairs.

Naked Pair
Two squares in a row, column or house with the same two notes and no others, so those numbers can't go anywhere else there.
Hidden Pair
Two numbers that can only go in the same two squares of a row, column or house, so those squares can't be anything else.

Fish Patterns

Advanced techniques built on one number's places across several rows and columns.

X-Wing
A number with exactly two places in each of two rows, in the same two columns, so it can't go anywhere else in those columns. The same works with rows and columns swapped.
Swordfish
The X-Wing idea with three rows: the number's places in three rows all sit in the same three columns, so it can't go anywhere else in those columns.
Jellyfish
The X-Wing idea with four rows: the number's places in four rows all sit in the same four columns, so it can't go anywhere else in those columns.

Quick Reference

Common Abbreviations

R1C1
Row 1, Column 1
B1
House 1 (top-left); B for box
{1,2,3}
A square's notes

Grid Numbering

  • Rows numbered 1-9 from top to bottom
  • Columns numbered 1-9 from left to right
  • Houses numbered 1-9 from top-left to bottom-right
