Hidden Single

A number with only one square left in a row, column or house, so it goes there, whatever else that square could hold. It's hidden because you find it by looking at the number, not at the square.

Worked example

Hidden Single in Action

How to spot it

  1. 1Pick a number and a house that doesn't have it yet.
  2. 2Look along the rows and columns that cross the house. Every one that already has the number rules out its squares.
  3. 3If only one square is left, the number goes there. Rows and columns work the same way.
  4. 4With notes, look for a note that's in only one square of a row, column or house.

What it does

Places a number. Most puzzles start with plenty of these, and every number you place can make more.
