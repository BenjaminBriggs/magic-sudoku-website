Crane

A number with only two places in a house and two in a row or column, where one end of each sees the other; one of the far ends must hold it, so any square that sees both can't.

Worked example

Crane in Action

How to spot it

  1. 1Pick a number and find a house where it has only two places.
  2. 2Find a row or column where it also has only two places, with one end seeing an end of the house's pair.
  3. 3Those two ends can't both hold the number, so one of the far ends must.
  4. 4Cross the number off any square that sees both far ends.

What it does

Crosses notes off, usually just one.
