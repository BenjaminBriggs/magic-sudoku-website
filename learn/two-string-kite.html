Two-String Kite

A number with only two places in a row and two in a column, with one end of each in the same house; one of the far ends must hold it, so any square that sees both can't.

Worked example

Two-String Kite in Action

How to spot it

  1. 1Pick a number and find a row and a column where it has only two places each.
  2. 2Check that one end of the row's pair and one end of the column's pair sit in the same house.
  3. 3Those two ends can't both hold the number, so one of the far ends must.
  4. 4Cross the number off any square that sees both far ends.

What it does

Crosses notes off, usually just one.
