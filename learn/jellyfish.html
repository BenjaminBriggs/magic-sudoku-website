Jellyfish

The X-Wing idea with four rows: the number's places in four rows all sit in the same four columns, so it can't go anywhere else in those columns.

01Worked Example 02With a Fin

Worked example

Jellyfish in Action

How to spot it

  1. 1Pick a number and look for rows where it has only two, three or four places left.
  2. 2Find four of those rows whose places, between them, sit in just four columns.
  3. 3Each row's copy of the number goes in one of those columns, and no column can take two, so each column's copy is in one of these rows.
  4. 4Cross the number off everywhere else in the four columns.

What it does

Crosses notes off. It's rare, and usually turns up only once simpler steps run out.

With a Fin

If one of the rows has an extra place or two for the number, all in one house, it's a Finned Jellyfish. You can still cross the number off, but only where the columns run through that house.

Finned Jellyfish in Action

Finned Jellyfish

Grandmaster

A Jellyfish with extra places inside one house, crossed off only where the columns run through that house.

How to spot it

  1. 1Pick a number and look for four rows whose places, between them, sit in just four columns, but for an extra place or two in one of them.
  2. 2Those extra places are the fin. They must all be in one house, along with one of their row's places in the four columns.
  3. 3If the Jellyfish holds, each column's copy is in these four rows. If the fin has the number, nothing else in its house can. Both ways, the number can't go where the columns run through the fin's house, outside these rows.
  4. 4Cross the number off there only, and leave the rest of the four columns alone.
