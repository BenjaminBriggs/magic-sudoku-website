4-Y-Wing

Four squares whose notes, between them, hold only four numbers, where all but one of the numbers can fill only one of the squares, because their places there all see each other. So the remaining number must go in one of them, and any square that sees every place it has there can't have it.

Worked example

4-Y-Wing in Action

How to spot it

  1. 1Look for four squares, not all in one row, column or house, whose notes hold only four numbers between them.
  2. 2For each number, check whether its places among the four all see each other. If they do, it can fill only one of them.
  3. 3If that's true of all but one number, the four squares need the remaining one too.
  4. 4Cross that number off any square that sees all its places in the group.

What it does

Crosses notes off, usually just one. An XY-Wing is the same idea with three squares.

With More Squares

Five, six or seven squares work the same way, as long as their notes hold only as many numbers as there are squares, and all but one of the numbers can fill only one of them. Each size has its own name, from 5-Y-Wing to 7-Y-Wing.

Related Techniques

XY-Wing

Advanced

Three squares with two notes each, a pivot and two wings, where whatever the pivot turns out to be, one wing gets the same number, so any square that sees both wings can't have it.

XYZ-Wing

Advanced

Like an XY-Wing, but the pivot also holds the wings' shared number, so it can only be crossed off squares that see all three.
