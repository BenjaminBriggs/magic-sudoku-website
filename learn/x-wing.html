X-Wing

A number with exactly two places in each of two rows, in the same two columns, so it can't go anywhere else in those columns. The same works with rows and columns swapped.

01Worked Example 02With a Fin

Worked example

X-Wing in Action

How to spot it

  1. 1Pick a number and look for rows where it has only two places left.
  2. 2Find two of those rows whose places sit in the same two columns. The four squares make a rectangle.
  3. 3The number goes in two opposite corners, so each column's copy is in one of these rows.
  4. 4Cross the number off everywhere else in the two columns.

What it does

Crosses notes off, often several at once.

With a Fin

If one of the rows has an extra place or two for the number, all in the same house as a corner, it's a Finned X-Wing. You can still cross the number off, but only where the columns run through that house.

Finned X-Wing in Action

Finned X-Wing

Master

An X-Wing with an extra place or two for the number inside one house, so it can only be crossed off where those columns run through that house.

How to spot it

  1. 1Pick a number and look for two rows whose places sit in the same two columns, but for an extra place or two in one of them.
  2. 2Those extra places are the fin. They must all be in one house, the same house as one of the four corners.
  3. 3If the X-Wing holds, each column's copy is in these two rows. If the fin has the number, nothing else in its house can. Both ways, the number can't go where the columns run through the fin's house, outside these rows.
  4. 4Cross the number off there only, and leave the rest of the two columns alone.

What it does

Crosses notes off, usually only one or two, all inside the fin's house.
