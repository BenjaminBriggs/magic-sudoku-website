Naked Singles

A naked single occurs when a cell has only one possible candidate remaining. This is the most basic and important solving technique.

Worked example

Naked Single in Action

When to use

  • Look for cells with only one candidate remaining
  • Check cells whose row, column, and box together already contain 8 different numbers
  • Always start with this technique—it's the most straightforward

Vocabulary tip

Notice how we use candidates and houses? These key terms from our glossary help describe exactly what's happening in each technique. Familiarizing yourself with these terms makes learning advanced strategies much easier!

2

Hidden Singles

A hidden single occurs when a number can only go in one place within a row, column, or box, even if that cell has multiple candidates.

Worked example

Hidden Single in Action

When to use

  • Scan each row, column, and box for missing numbers
  • Check if a missing number can only fit in one cell of that unit
  • Often more powerful than naked singles in advanced puzzles
