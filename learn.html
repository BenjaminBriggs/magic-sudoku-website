Hidden Single

A number with only one square left in a row, column or house, so it goes there, whatever else that square could hold. It's hidden because you find it by looking at the number, not at the square.

Locked Candidates

A number whose squares in one house all sit in one row or column, so it can't go anywhere else in that line; or whose squares in a row or column all sit in one house, so it can't go anywhere else in that house.

BUG+1

Every empty square has two notes except one with three; the number that appears three times in that square's row, column and house goes there, or the puzzle would have two answers.

8 Advanced

X-Wing

A number with exactly two places in each of two rows, in the same two columns, so it can't go anywhere else in those columns. The same works with rows and columns swapped.

Open lesson →
9 Advanced

Unique Rectangle Type 1

Four squares at the corners of a rectangle across two houses, three with only the same two notes: the fourth can't be either number, or the puzzle would have two answers.

10 Advanced

Swordfish

The X-Wing idea with three rows: the number's places in three rows all sit in the same three columns, so it can't go anywhere else in those columns.

Open lesson →
11 Advanced

XY-Wing

Three squares with two notes each, a pivot and two wings, where whatever the pivot turns out to be, one wing gets the same number, so any square that sees both wings can't have it.

12 Advanced

XYZ-Wing

Like an XY-Wing, but the pivot also holds the wings' shared number, so it can only be crossed off squares that see all three.

13 Expert

Skyscraper

A number with only two places in each of two rows, where one place in each shares a column; one of the other two places must hold it, so any square that sees both can't. The same works with rows and columns swapped.

Open lesson →
14 Expert

Two-String Kite

A number with only two places in a row and two in a column, with one end of each in the same house; one of the far ends must hold it, so any square that sees both can't.

Open lesson →
15 Expert

Crane

A number with only two places in a house and two in a row or column, where one end of each sees the other; one of the far ends must hold it, so any square that sees both can't.

Open lesson →
16 Expert

Empty Rectangle

A number whose places in one house all sit in one row and one column of it, but not all in one line, working with a row or column that doesn't cross the house and has only two places for it, to rule it out of one square.

17 Expert

W-Wing

Two squares with the same two notes, linked through a row, column or house where one of those numbers has only two places; one of the squares must hold the other number, so any square that sees both can't.

Jellyfish

The X-Wing idea with four rows: the number's places in four rows all sit in the same four columns, so it can't go anywhere else in those columns.

Open lesson →
19 Master

4-Y-Wing

Four squares whose notes, between them, hold only four numbers, where all but one of the numbers can fill only one of the squares, because their places there all see each other. So the remaining number must go in one of them, and any square that sees every place it has there can't have it.
